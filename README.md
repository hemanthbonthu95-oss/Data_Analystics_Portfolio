📊 Wayfair Sales Analysis Dashboard – Guided Project

Built in Power BI using the dataset from DataCareers.com, this project demonstrates:

🔎 Revenue breakdown by category & product

👥 Top customers driving sales

📈 Year‑on‑year revenue growth (2024 vs 2025)

📦 Order distribution with returns & cancellations

The dashboard combines advanced DAX, clear data modeling, and a minimal flat UI theme to highlight seasonal patterns and business insights.

🚀 This project shows how data storytelling can transform raw sales data into actionable insights for stakeholders.
